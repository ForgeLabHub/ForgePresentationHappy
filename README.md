# Концепция счастья — комплект доклада

Учебная работа: «Концепция счастья: что делает людей счастливыми в современном мире?»
(РКСИ, группа ИС-24). Репозиторий содержит **готовые артефакты доклада**, а не код:
презентации, PDF, текст выступления, инструкцию защиты, вероятные вопросы, видео и
автономную HTML-версию.

## Проверка целостности

Бинарные файлы нельзя проверить в diff, поэтому их контрольные суммы зафиксированы:

```bash
make verify        # сверить все артефакты с MANIFEST.sha256
make formats       # убедиться, что каждый файл действительно открывается
make docs-check    # проверить ссылки и актуальность индекса слайдов
make verify-all    # всё перечисленное
make package       # собрать комплект для сдачи в dist/ с SHA256SUMS
```

| Команда | Что делает |
| --- | --- |
| `make doctor` | инструменты, размеры файлов, лимиты GitHub (100 МБ на файл) |
| `make verify` | целостность по `MANIFEST.sha256` |
| `make formats` | `.pptx`/`.docx`/`.pdf`/`.mp4`/`.html` парсятся, а не только названы так |
| `make outline` | пересобрать индекс слайдов из презентации |
| `make package` | `dist/` с минимальным комплектом и контрольными суммами |

Матрица «утверждение → проверка → CI» — [docs/verification/matrix.md](docs/verification/matrix.md).
Индекс всей документации — [docs/index.md](docs/index.md).

> При замене любого файла: заменить → `make checksums` → проверить diff манифеста →
> закоммитить вместе. Иначе `make verify` (и CI) законно упадут.
