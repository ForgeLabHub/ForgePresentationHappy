# Индекс документации

Этот репозиторий — не код, а **комплект артефактов** доклада «Концепция счастья:
что делает людей счастливыми в современном мире». Поэтому проверяется не сборка, а
целостность файлов, их открываемость и комплектность поставки.

| Нужно | Где |
| --- | --- |
| Понять, какой файл для чего | [content/materials.md](content/materials.md) |
| Узнать содержание презентации без PowerPoint | [content/slides.md](content/slides.md) — 17 слайдов с тезисами и текстом доклада |
| Источники и библиография | [../README.md](../README.md) — список из 20 источников |
| Проверить, что файлы не подменены | [verification/matrix.md](verification/matrix.md), `make verify` |
| Собрать комплект для сдачи | `make package` → `dist/` с `SHA256SUMS` |
| Что найдено при аудите | [audit/content-audit-2026-10-29.md](audit/content-audit-2026-10-29.md) |

## Правила

1. **Бинарные файлы не проверяются глазами в diff.** Их целостность фиксирует
   `MANIFEST.sha256`; `make verify` падает, если файл изменился без обновления манифеста.
2. **Содержание должно читаться как текст.** `docs/content/slides.md` генерируется из
   `.pptx` (`make outline`) и сверяется в CI: расхождение числа слайдов — ошибка.
3. **Замена файла — осознанное действие:** сначала заменить, затем
   `make checksums`, затем проверить diff манифеста и закоммитить вместе.
4. Ссылки в документации проверяются автоматически (`make docs-check`).
