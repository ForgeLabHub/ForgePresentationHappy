# Матрица проверок

| Проверка | Что доказывает | Команда | CI |
| --- | --- | --- | --- |
| Контрольные суммы | файлы не подменены и не обрезаны | `make verify` | `ci.yml` → `integrity` |
| Все артефакты учтены | новый файл не появился без записи в манифест | `make verify` | `ci.yml` → `integrity` |
| Форматы открываются | `.pptx`/`.docx`/`.pdf`/`.mp4`/`.html` парсятся, а не только названы так | `make formats` | `ci.yml` → `formats` |
| Индекс слайдов актуален | число слайдов в файле совпадает с `docs/content/slides.md` | `make docs-check` | `ci.yml` → `docs` |
| Ссылки в документации живые | нет битых относительных путей | `make docs-check` | `ci.yml` → `docs` |
| Размеры в пределах лимитов GitHub | репозиторий останется клонируемым (100 МБ на файл) | `make doctor` | `ci.yml` → `integrity` |
| Комплект для сдачи собирается | `make package` даёт `dist/` с суммами | `make package` | локально |

## Что не проверяется автоматически

- Визуальное качество слайдов и вёрстки: проверяется человеком при показе.
- Смысловая точность источников: список литературы в `../README.md`.
- Воспроизведение анимации: зависит от PowerPoint и машины; для надёжности
  предусмотрена версия без анимаций и PDF.
- Соответствие видео финальной версии презентации — проверяется вручную при
  обновлении (`make formats` подтвердит только целостность контейнера).
